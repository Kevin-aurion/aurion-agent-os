# 03 — Agent 被擋下的越矩行為自動進 FDE 佇列

**What to build:** 當 Agent 試圖做被禁止的事（執行 shell、寄信、操控電腦、寫雲端、超出預算、寫出沙盒），除了照舊被擋下來之外，FDE 的佇列會自動出現一筆帶證據的提案（哪個員工、哪次執行、想做什麼被擋），讓 FDE 決定要放寬限制還是修技能。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 任一硬性限制被觸發 → 佇列出現一筆「越矩」來源的提案，含員工、執行、被擋動作
- [ ] **攔截行為本身完全不變**：該動作仍然被拒絕（不因為要記錄而放行）
- [ ] 預算超限（fail-closed 阻斷）同樣產生提案
- [ ] 提案建立失敗不得影響執行流程（記錄失敗只寫 log）
- [ ] 同一次執行重複觸發同類越矩不應洗出大量重複提案
