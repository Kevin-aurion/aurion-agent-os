# 01 — 共用「路徑守門」與「CJK slug」工具

**What to build:** 開發者在任何接受外部輸入的地方，都能用同一組工具確保「檔案只會寫在該寫的根目錄內」，以及「中文名稱也能得到穩定、非空、可辨識的 slug」。此票只建工具並自帶測試，不改任何呼叫點（expand，不 contract）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 提供「resolve 後斷言仍在指定根目錄內」的守門函式；同前綴不同目錄（例如根目錄後接字元）不得被誤放行
- [ ] 提供安全的路徑組合與單一片段清洗（清除路徑分隔符、保留字元、純點號片段）
- [ ] slug 保留 CJK 字元、英數小寫化、維持長度上限；「每日帳款掃描」不得產生空字串
- [ ] slug 對同一輸入穩定（同輸入同輸出）；空結果退回穩定短雜湊
- [ ] 純函式、可單獨 import 測試；`tsc --noEmit` 通過
