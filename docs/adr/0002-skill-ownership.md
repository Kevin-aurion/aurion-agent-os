# ADR 0002 — 訓練產出的 Skill 為全域資產，確認後自動掛載給該員工

**狀態**：已接受（2026-07）

## 脈絡
訓練對話發生在「員工詳情 → 訓練」（有該員工的上下文），但 Skill 在資料模型上是全域資產（`Skill` + `AgentSkill` 掛載）。需決定產出物歸屬。

## 決策
產出的 Skill 進**全域技能庫**；FDE 確認後**自動掛載**給發起訓練的那位員工，其他員工亦可複用。

## 後果
- 不需修改 schema（沿用 `Skill` + `AgentSkill`）。
- 符合第一性原理「技能／記憶歸公司，不歸個人」。
- 需注意命名衝突：全域 slug 唯一，已由共用 `lib/slug.ts` + uniqueSlug 處理。
