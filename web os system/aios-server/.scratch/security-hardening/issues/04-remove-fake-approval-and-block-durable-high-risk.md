# 04 — 移除假核准後門，並拒絕「耐久 + 高風險」組合

**What to build:** 老闆能信任高風險員工一定要真人核准：系統不再接受「傳一個字串就算核准」。同時，會卡死又會繞過治理的「耐久工作流 + 高風險員工」組合，在建立／啟用與派工時被明確擋下並說明原因，而不是讓那次執行永久等待。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 核准判定不再只看「有無傳識別碼」；耐久路徑不得自行偽造核准識別碼
- [ ] 高風險員工 + 耐久工作流：建立／啟用時拒絕並回明確錯誤
- [ ] 派工時再次守門（fail-closed），即使資料already存在也不會進入永久等待
- [ ] 負向測試：嘗試以偽造識別碼繞過高風險閘 → 失敗
- [ ] 既有 in-process 高風險 HITL 行為零回歸（仍會停在待審並可核准／駁回）
