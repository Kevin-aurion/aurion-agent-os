# 05 — 錄一次操作，由 Record & Replay 自己把它變成技能

**What to build:** 使用者在我們的網頁按「開始錄製」，網頁顯示「正在錄製中」；使用者去做他要做的事；回來按「結束錄製」，系統就請 **Codex 的 Record & Replay 自己**把這段錄製變成一個技能，然後把該技能收進我們的系統，停在待 FDE 確認。

**重要**：我們**不**自行解析錄製內容、**不**產生 JSON 或腳本中間格式——「變成技能」這件事交給 Record & Replay／skill-creator 做，我們只負責起停、觸發、以及把產出的技能匯入。

**Blocked by:** 01, 04

**Status:** ready-for-agent

- [ ] 網頁可「開始錄製」，並持續顯示錄製中狀態（可查詢目前狀態）
- [ ] 同時只允許一個進行中的錄製；已在錄製時再按開始 → 回報既有錄製，不會重啟
- [ ] 網頁可「結束錄製」
- [ ] 結束後由 Codex（該員工主引擎為 CODEX）自行產出技能，我們不解析錄製內容
- [ ] 產出的技能被匯入系統，標記為「錄製產生」，且**停在待確認**（永不自動確認）
- [ ] 匯入時套用紅線遮罩（密碼／OTP／金鑰／卡號不得出現在技能中）
- [ ] FDE 確認後可掛載給該員工，並同時存在於共用技能庫
- [ ] 使用者取消錄製 → 不產生任何技能
- [ ] 缺少系統輔助使用權限或 Codex 元件不可用時，回明確錯誤而非靜默失敗
