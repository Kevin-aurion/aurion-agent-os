# 06 — 語意越矩審查（超出身分卡授權）

**What to build:** 即使沒有觸發任何硬性限制，若 Agent 的輸出超出其身分卡「不可做」的範圍（例如擅自承諾折扣），驗證閘會判定為語意越矩並產生提案；但只有高嚴重度或高信心的判定才會進 FDE 佇列，避免洗版。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 驗證階段會針對「是否超出身分卡授權」做判定
- [ ] 高嚴重度／高信心 → 進 FDE 佇列，來源標為語意審查
- [ ] 低信心 → 只記錄，不進佇列
- [ ] 跨模型驗證閘的原有判決語義（執行≠驗證、fail-closed）完全不變
- [ ] 沒有身分卡的員工不會產生誤判提案
