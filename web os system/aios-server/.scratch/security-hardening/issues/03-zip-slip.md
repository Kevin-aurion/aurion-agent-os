# 03 — 惡意技能 zip 不得寫出技能資料夾（Zip Slip）

**What to build:** 上傳技能 zip 時，所有項目只會被解到該技能自己的資料夾底下；含 `..`、絕對路徑或磁碟機前綴的項目會讓整包被拒絕並回報明確錯誤，主機其他位置不會被寫入。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 每個 zip 項目名稱先清洗並斷言落在該技能根目錄內
- [ ] 含 `..`／絕對路徑／磁碟機前綴的項目 → 拒絕整包並回明確錯誤訊息
- [ ] 負向測試：構造惡意 zip，斷言目標外檔案**未被建立**且 API 回錯
- [ ] 正向測試：正常 zip（含 SKILL.md 與附件）仍能正確解開
- [ ] 改動限於 zip 解壓路徑，不牽動該路由其他既有行為
