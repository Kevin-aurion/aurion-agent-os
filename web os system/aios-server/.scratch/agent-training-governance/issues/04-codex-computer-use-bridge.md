# 04 — 員工能真的操控電腦（經 Codex 的 Computer Use）

**What to build:** 主引擎為 CODEX 的員工，在執行需要電腦操控的步驟時，能實際列出應用程式、讀取視窗狀態、點擊、輸入文字、按鍵、捲動，並在動作後驗證結果。若員工未被授權電腦操控，一律拒絕。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 能連上 Codex 隨附的電腦操控 MCP 並取得其工具清單
- [ ] 未授權電腦操控的員工 → 一律拒絕（既有硬閘不回歸）
- [ ] 授權的員工可執行「列出應用程式／讀取視窗狀態」並取回結果
- [ ] 工具清單與預期不符（版本漂移）時，回明確錯誤而非靜默失敗
- [ ] 缺少系統輔助使用權限時，錯誤訊息說得出原因與解法
