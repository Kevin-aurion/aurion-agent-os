# 07 — 聊天式技能工廠（前端）

**What to build:** 操作者在員工詳情的「訓練」頁，用聊天方式描述要做的流程，系統回覆草擬結果；也能問「這位員工目前有哪些流程」得到白話清單；草稿以卡片呈現，FDE 才看得到確認按鈕。錄製按鈕也在同一頁。

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [ ] 訓練頁是對話串（送出訊息 → 顯示草擬中 → 顯示草稿卡）
- [ ] 可問「有哪些流程」並看到白話清單（技能＋工作流）
- [ ] 草稿卡顯示理解結果（能做什麼、讀寫什麼、不可逆動作、風險）
- [ ] 只有 FDE 看得到／按得到「確認掛載」；操作者看到的是「送出提案」
- [ ] 同頁有錄製入口（開始／停止），狀態可見
- [ ] 既有頁籤與功能不回歸
