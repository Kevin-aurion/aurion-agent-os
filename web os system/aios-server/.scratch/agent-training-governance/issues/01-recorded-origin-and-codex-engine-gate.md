# 01 — 錄製／電腦操控技能只能掛在 CODEX 員工上

**What to build:** FDE 把「需要電腦操控或由錄製產生」的技能掛給一位主引擎不是 CODEX 的員工時，系統當場拒絕並說明原因；掛給 CODEX 員工則正常成功。技能上也看得出它是錄製來的。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 技能來源可標記為「錄製產生」
- [ ] 掛載 錄製／電腦操控 技能到非 CODEX 主引擎的員工 → 拒絕，錯誤訊息說明「這類技能只能由 CODEX 引擎驅動」
- [ ] 掛載到 CODEX 員工 → 成功
- [ ] 既有一般技能（文字型）的掛載行為完全不變
- [ ] 電腦操控技能仍被強制為桌面執行環境（既有行為不回歸）
