# 02 — FDE 的單一待審提案佇列

**What to build:** FDE 能在一個地方看到所有待審的變更提案（誰提的、對哪個員工、想改什麼、來源、嚴重度），並能核准或駁回。核准後變更真的生效並留下可回滾的版本；駁回後系統毫無變動。操作者只能提案，不能讓它生效。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 操作者（一般成員）可提出「修正建議」或「追加限制」的提案，狀態為待審
- [ ] 操作者無法核准任何提案（被拒絕）
- [ ] FDE 可列出待審提案，含來源、目標、嚴重度、提出者
- [ ] FDE 核准「技能類」提案 → 產生新的技能版本，可回滾到舊版
- [ ] FDE 核准「限制類」提案 → 該員工的限制實際更新
- [ ] FDE 駁回提案 → 目標物完全未被修改
- [ ] 每次決議都寫入稽核紀錄
