# ADR 0001 — 三個訓練入口共用單一「技能工廠」與治理管線

**狀態**：已接受（2026-07）

## 脈絡
口述/聊天訓練（#3）與「錄製操作 → 自動化 Skill」（#4）本質上都是產出一個 Skill。若各自實作，會出現兩套草稿狀態機、兩套確認 UI、兩套版本化與 rollback。

## 決策
三個入口——①打字/語音描述 ②上傳現成 Skill ③錄製操作——共用**同一個技能工廠介面**與**同一條治理管線**：
草稿 → 跨模型 understand 理解 → **FDE 人工確認** → 掛載 → 版本化（stable/canary）／rollback。

## 後果
- 只維護一套 `reviewStatus` 狀態機與確認 UI。
- 錄製功能日後接上時，只是多一個「草稿來源」，不需新治理路徑。
- 需在 `Skill.origin` 增加錄製來源類型（未定案，見後續 ADR）。
