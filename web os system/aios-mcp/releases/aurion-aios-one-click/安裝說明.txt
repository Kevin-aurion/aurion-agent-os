Aurion AIOS Agent Builder 一鍵安裝
=================================

這個安裝包不會在客戶電腦安裝 AIOS server、資料庫、Tunnel 或本機 MCP 服務。
它只會安裝 Claude Plugin，並連線至 Aurion 的公開 OAuth Remote MCP：

https://aurion-aios-mcp.lazyoffice.app/mcp

macOS：雙擊「Install Aurion AIOS.command」
Windows：右鍵「Install-Aurion-AIOS.ps1」，選擇使用 PowerShell 執行

需求：電腦已安裝 Claude Code CLI。

安裝完成後：
1. 重新啟動 Claude。
2. 直接說「我想建立一位……的 AI 員工」。
3. 第一次使用會開啟 AIOS 登入與 OAuth 授權頁；請使用自己的 AIOS 帳號。
4. 對話與背景 Agent／Skill 草稿會傳回中央 AIOS。
5. 到 https://aurion-aios.lazyoffice.app/agent-builds 查看。

如果只使用 Claude Chat 而沒有 Claude Code CLI：
1. 在 Claude 的 Connectors 設定加入上面的 Remote MCP URL，完成登入授權。
2. 上傳同包內的 build-aios-agent.skill.zip。

注意：Claude Chat 自訂 Skill ZIP 本身不能自動新增 Connector；這是 Claude 平台目前的產品邊界。
