# 02 — 部門名稱不得把員工檔案寫出工作區

**What to build:** 訓練師把員工部門命名成任何文字（含 `..`、`.`、路徑分隔符）時，具現化員工只會寫在員工工作區底下；若計算出的目錄落在工作區之外，具現化直接失敗並回報，而不是靜默寫出去。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 部門清洗會剔除純點號片段（`..`、`.`）
- [ ] 具現化前斷言員工目錄位於員工根目錄內，否則拒絕並拋出清楚錯誤
- [ ] 負向測試：部門為 `..` 時，工作區之外**沒有**任何檔案被建立
- [ ] 正向測試：正常部門（含中文）仍能正確具現化
- [ ] `tsc --noEmit` 通過
